# Contributing to JJN Client

Thank you for your interest in improving JJN Client.

## Guidelines

1. Keep the Liquid Glass design language consistent.
2. Prefer modular, self-contained features.
3. UI changes should live in the `launcher/` directory.
4. Gameplay / HUD / mod logic belongs in the `client/` Fabric mod.
5. Write clean, readable code with clear naming.

## Getting Started

1. Fork the repository
2. Create a feature branch
3. Make your changes
4. Open a Pull Request with a clear description

## Code Style

- TypeScript / React for the launcher
- Java 21 for the Fabric mod
- Follow existing patterns for mods and HUD components
